CMake fetches upstream source, including its license files, into the build dependency directory. Distribution packaging must retain the upstream license notices. `package.ps1` copies these into the generated distribution.

`tools/fetch-v8-sdk.ps1` verifies the compressed static library, uncompressed library, matching header archive and wrapper license against pinned SHA-256 hashes. The library contains its startup snapshot; no external runtime DLL or snapshot file is needed. `build/v8-sdk/manifest.json` records build configuration and license hashes. SDK packaging retains this manifest and the V8/wrapper/third-party notices under `licenses/`, while compiler headers, static libraries and demos remain development files.

The Windows library uses libc++ internally, so the host uses the upstream platform C-ABI factory/destructor rather than exchanging C++ standard-library ownership types across compiler ABIs. `tools/prepare-v8-platform-object.cjs` retains only those two original functions and their COFF relocation/unwind dependencies from the monolithic Rust binding object; executable bytes are unchanged. The original and derived object hashes are pinned, and the retained sections/symbols are recorded in the SDK manifest. Unused Rust inspector/serialization delegates are excluded instead of supplying callback stubs. The V8 engine itself is unchanged.


LuaSTG and the local Touhou20Reconstruction tree are architecture/mechanics references, not native build dependencies. TS-STG does not load or distribute original executable code. The default `package.ps1` output contains only the engine, thlib and necessary documentation/licenses; demos and title-specific resources are excluded. The generic demo uses script-drawn graphics and authored audio generated by `tools/generate-audio.mjs` and is not release payload.

thlib includes common materials. Six synthesized sound cues are original MIT assets. The bundled `packages/thlib/assets/reference-common` visual pack selects standard bullets, laser strips, Bomb orb/beam and effect artwork from the user's existing reference resources. Its 23 PNGs are unchanged originals, not MIT artwork. The complete `packages/thlib/assets/touhou-common` pack adds restored Reimu/Marisa bodies, options, weapons, Bombs, focus effects, enemies, items, full animation instructions, baseline shot data and 51 original sound files. Mixed atlases preserve selected RGBA pixels and their one-pixel sampling border while making exclusive regions transparent; whole common images are unchanged. Those packs' NOTICE.md and manifests retain Team Shanghai Alice / ZUN provenance, filtering details, hashes and original resource rights. `packages/thlib/assets/spell-common` contains three reusable effect textures imported from the local Rush archive, with its own NOTICE and per-file provenance. Common describes reusable purpose, not confirmed byte identity across every Touhou title. All three common packs are versioned in the private repository and included in thlib packages; inclusion does not change the original resource rights or the scope of the MIT code license.
