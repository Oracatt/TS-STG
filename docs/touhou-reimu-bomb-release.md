# 灵梦 Bomb 法球的退场生命周期

公共实现是 [`TouhouReimuBomb`](../packages/thlib/src/touhou/bombs.js)，由 `TouhouPlayer` 持有。灵梦的 Bomb 规则和 `pl00` 通用动画属于 thlib，使用方不需要在关卡或 Boss 脚本中补退场特效。

## 修复的行为

此前法球退出时只向 ANM 容器 46 发送事件 1。容器会开始生成碎片并等待 60 帧，但是绘制法球本体的六个 49/51/53 子动画没有收到事件，仍在原地循环。容器删除时这些本体才一起消失，因此出现法球残留后突然消失的画面。

现在 `retireOrb()` 使用 `interrupt(1, true)`，向容器及已有子动画传递原事件。法球本体当帧结束，原脚本接着产生六个退场碎片和一个闪光，保留原来的位移、缩放与透明度插值。没有替换素材或额外添加淡出曲线。

240 帧的统一退场还会重新通知已经停止运动、但容器尚未结束的法球。这与原作 `retire_reimu_orb()` 一致：`active` 只控制音效、消弹和爆炸伤害，中断在条件外。重复通知可以重新生成该容器的退场动画，但不会重复伤害、消弹或播放退休音效。已删除的动画不会复活。

ANM 更新统一放到灵梦 Bomb 规则处理之后，每帧一次，包括 240 帧分支。原作先运行 Bomb 回调，再运行普通 ANM 回调；因此累计伤害退休和 240 帧退休的事件都应在当帧被动画处理。完成判定仍在动画更新前检查，不把视觉尾当成继续攻击的法球。

## 原脚本的时间线

计时以 60 Hz 游戏更新为单位；以下寿命来自 `pl00` 的 ANM 指令。

| 动画 | 事件 1 后的行为 |
| --- | --- |
| 46 法球容器 | 生成两组 50/52/54 以及 48，等待 60 帧后删除 |
| 49/51/53 法球本体，共六个 | 收到事件 1 后删除，不继续原来的循环 |
| 50/52/54 碎片，共六个 | 按原随机方向散开，50 帧内缩小并淡出 |
| 48 闪光 | 20 帧内扩张并淡出 |
| 61 背景光环 | 240 帧收到事件后，按原指令用 20 帧淡出 |

容器寿命长于可见碎片寿命；最后约 10 帧保留的是不可见容器，不能据此继续绘制完整法球。

Bomb 从 120 帧起检查法球动画是否全部结束。如果全部结束，原作同帧完成并销毁 Bomb，基类析构直接删除背景光环。因此提前完成时不强行补足光环的 20 帧尾动画；正常 240 帧统一退场则有机会完整播放该淡出。

## 伤害与视觉的边界

活动法球的伤害圆半径为 56，每 3 帧判定一次，累计伤害达到 300 后退休。第一次退休会生成半径 64、每帧增长 8、持续 11 帧、伤害为 100 的独立爆炸区，并执行原来的半径 128 消弹。退休后法球停止运动和持续伤害；后续 50 帧碎片只负责显示，不延长攻击、消弹或爆炸区寿命。
