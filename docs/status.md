# 当前还原范围与缺口

验收目标是用户要求的原作一致性；当前还没有达到整作完全一致。这里区分已有源码实现、已经验证的函数/场景以及仍缺少的通用系统，不能用旧版通用模板的完成度代替原作还原。

## 尚不能称为完全还原的部分

- 没有以原游戏整局录像和逐帧输入作为基准做端到端对照，也没有完成逐像素或音频采样对比。重建源码本身的未恢复行为同样会限制结论。
- 示例的道中、敌群和攻击时间轴是为验证引擎编写的 JS 场景，不是原关卡。具体锦上京 Boss 已按用户要求排除；ECL/STD 场景和其他作品的完整关卡未自动导入。
- ANM 部分特殊指令、相机分支和几何类型仍需扩展，未覆盖的入口明确抛出错误。支持一段动画不等于它的全部中断、相机与时钟倍率都验证过。
- 通用 Boss 的战斗调度仍由使用方编写；不能把已有血量/符卡机制说成所有 Boss 演出、对话和切换流程已经完成。
- 动态标题在 Windows 原生宿主自动接入公共 GDI 字图；其他平台适配器需实现对应的字体/编码/位图接口。不能由本机字图一致推断其他字体配置或操作系统也完全相同。
- 原作 Replay 二进制兼容、录像保存/选择页面、完整成绩/练习/手册/设置/键位页面尚未全部接入。通用库已有自己的回放格式，它不等于原作录像兼容。
- 部分伤害区域的所有权、命中回调、ECL 发射联动，以及激光反弹/特殊多边形消除等分支未实现；相关接口或指令会明确报错，避免静默替代。
- GPU 后端是 raylib/OpenGL；D3D 像素中心、滤波和线覆盖尚未逐像素比对。BGM 按原循环位置播放，但边界在显示帧更新时检查，不是原音频采样级调度。
- 只验证了 Windows x64 / VS2019。不能把 Node 性能数字当作 QuickJS 帧率，也没有声明其他后端/平台可用。

原作魔石、魔石选择页、魔石资源计数和锦上京具体 Boss 为明确排除项；源消弹奖励若请求魔石会跳过，不随意替换为另一种奖励。其他通用系统的未完成项属于后续还原工作，并非用户取消的要求。
