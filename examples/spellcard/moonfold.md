# 月折「借光的纸鹤」

[moonfold.spell.js](moonfold.spell.js) 是一张可以直接编辑的 JavaScript 符卡示例：`spellCard` 定义名称、时长、血量和初始位置，`createSpell(context)` 用普通函数与逐帧逻辑编排攻击。弹幕、弹雾、判定、聚能和音效调用公共 thlib；不需要事件编辑器或额外素材。

## 在编辑器中打开

1. 运行仓库根目录的 [start-spellcard-editor.cmd](../../start-spellcard-editor.cmd)。原生引擎和公共素材需已准备好。
2. 如果编辑器当前有要保留的内容，先点击“另存为”保存成自己的 `.spell.js` 文件。
3. 点击左上角“打开”，选择 `D:\AIWorkspace\TS-STG\examples\spellcard\moonfold.spell.js`。源码会载入左侧，右侧建立原生预览。
4. 点击预览下方“播放”。如果关闭了“自动运行”，先点击顶部“运行”或按 **Ctrl+Enter**。

点击游戏画面后，方向键移动，Shift 低速，Z 射击，X 使用 Bomb。想完整观看 45 秒的编排，可以先不射击；击破会进入正常的符卡收尾流程。

示例文件本身不会替换用户草稿。编辑器在打开文件和修改源码后会自动保存当前内容为草稿，因此切换到示例前应先保存原有内容；修改示例时也建议“另存为”自己的版本。

## 45 秒的节奏

开头 2 秒聚能，随后是五段各 8 秒的乐句，最后留 3 秒收尾。青蓝与紫蓝的两条折线组成纸翼，少量白札标出折角；月牙出现在通道另一侧。纸翼向下展开，空隙按 **左、右、左、右、左** 交替，后半段略收窄；最后两段的金色笔画由三束增加为五束。

每段只捕捉一次自机方向，短暂聚能后连续写出三次金针笔画；玩家移动不会让整组金针继续转向追踪。读清蓝色空隙，将金针引向旧位置，等本段最后一层纸翼通过身边，再横移到下一侧。换边段停止新增攻击，让纸翼、月牙与金针的先后关系成为主要节奏。

## 直接修改代码

- `paperWing()`：纸翼折线、通道位置、宽度和下落速度。
- `crescent()`：月牙轮廓与两道弧线的间距。
- `goldenInk()`：金针束数、角度间隔和笔画长度。
- `update()`：五段编排、一次瞄准的时机和换边留白。

开启“自动运行”时，停止输入约 450 ms 后会重新加载源码；也可用 **Ctrl+Enter** 立即应用。所有逻辑都在这个 JS 文件中，可以添加自己的函数、循环和状态。底部进度条、暂停和单步用于观察具体帧；改动密度或速度后，也要连着播放前后两段，检查旧弹幕是否挡住下一次换边。
