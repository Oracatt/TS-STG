# 月折「借光的纸鹤」

[moonfold.spell.js](moonfold.spell.js) 是一张可以直接编辑的 JavaScript 符卡示例：`spellCard` 定义名称、时长、血量和初始位置，`createSpell(context)` 用普通函数与逐帧逻辑编排攻击。弹幕、弹雾、判定、聚能和音效调用公共 thlib；不需要事件编辑器或额外素材。

## 在编辑器中打开

1. 运行仓库根目录的 [start-spellcard-editor.cmd](../../start-spellcard-editor.cmd)。原生引擎和公共素材需已准备好。
2. 如果编辑器当前有要保留的内容，先点击“另存为”保存成自己的 `.spell.js` 文件。
3. 点击左上角“打开”，选择 `D:\AIWorkspace\TS-STG\examples\spellcard\moonfold.spell.js`。源码会载入左侧，右侧建立原生预览。
4. 点击预览下方“播放”。如果关闭了“自动运行”，先点击顶部“运行”或按 **Ctrl+Enter**。

点击游戏画面后，方向键移动，Shift 低速，Z 射击，X 使用 Bomb。默认是真实试玩，使用 thlib 的中弹、死亡、复活和失败菜单。勾选“无敌观察”可从头观看完整的 45 秒编排，也可拖动进度条；想看完全部弹路时先不射击。击破会进入正常的符卡收尾流程。

示例文件本身不会替换用户草稿。编辑器在打开文件和修改源码后会自动保存当前内容为草稿，因此切换到示例前应先保存原有内容；修改示例时也建议“另存为”自己的版本。

## 45 秒的节奏

聚能后，青蓝纸翼与稍晚展开的紫色残月持续向外扩散，白札标出折角。每组留出斜下方左右两处较宽缺口，位置随波次轻轻摆动；普通弹粒之间也保留间距。后半程出弹逐渐加快，金针的笔画略加长，最后停止新增攻击，留下收尾时间。

金色聚能连续出现三次，每次都重新捕捉当时的自机方向，再延迟发射一束金针。锁定以后，金针不再转向；提前移动会改变下一次瞄准。读弹时同时看青蓝纸翼、后到的紫色层，以及此前留下的金针。

- **留在一侧诱导**：在较宽缺口附近，看到金色聚能后小幅移开，让金针写向刚才的位置，再判断下一层纸翼。
- **找缝换位**：利用相邻弹粒与前后两层的间距，向另一缺口或更靠前的位置移动，改变下一束金针的落点。先看旧金针是否封住横移路线，不必按固定左右顺序换边。

这两种思路可以在一局内交替使用；缺口是读弹的起点，不是一直安全的固定通道。

## 直接修改代码

- `foldedMoon()`：纸翼轮廓、两个缺口、弹粒间距和扩散速度。
- `lockInk()`：每次瞄准的取样与聚能预兆。
- `writeInk()`：金针的角度间隔和笔画长度。
- `update()`：纸翼波次、第二层延迟与重复瞄准的节奏。

开启“自动运行”时，停止输入约 450 ms 后会重新加载源码；也可用 **Ctrl+Enter** 立即应用。真实试玩从头开始，无敌观察则重新模拟到当前帧。所有逻辑都在这个 JS 文件中，可以添加自己的函数、循环和状态。暂停和单步用于观察具体帧；改动密度或速度后，也要连续试玩，检查前后纸翼和旧金针叠加后的空间。
